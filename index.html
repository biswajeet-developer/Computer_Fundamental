📋 Complete Computer & Web Cheat Sheet

Instant reference guide to shortcuts, hardware, web technologies, and SEO:

Top Universal Shortcuts
  • Ctrl+C = Copy
  • Ctrl+V = Paste
  • Ctrl+X = Cut
  • Ctrl+Z = Undo
  • Ctrl+S = Save
  • Ctrl+F = Find in page
  • Alt+Tab = Switch open apps
  • Win+D = Show desktop
  • Win+Shift+S = Snipping screenshot
  • Win+V = Clipboard history
Hardware at a Glance
  • CPU: The Brain (Calculations in GHz)
  • RAM: The Desk (Temporary speed memory)
  • SSD: The Filing Cabinet (Permanent NVMe)
  • Motherboard: The Nervous System
  • GPU: Calculates visual pixels & 3D gaming
  • PSU: Converts AC wall power to DC electricity
Web Languages & Status Codes
  • HTML = The Skeleton (structure & tags)
  • CSS = The Styling (colors, layouts, dark mode)
  • JavaScript = The Brain (interactivity & logic)
  • 200 OK = Page loaded successfully
  • 301 = Page moved permanently
  • 404 = Page Not Found (Broken link)
  • 500 = Server internal crash/error
SEO & Web Architecture
  • DNS A Record: Maps domain $\to$ IPv4
  • CDN: Edge cache servers for global speed
  • SEO: Crawl $\to$ Index $\to$ Rank algorithm
  • Alt Text: Vital for blind screen readers & Google
  • Mobile-First: Google ranks mobile version first
